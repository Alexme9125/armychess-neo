# 现代化陆军棋（军棋）· 液态玻璃与云母对战系统

基于 **React 19 + TypeScript + Node.js + Socket.IO + Canvas/WebGL + Web Audio** 从零打造的现代化全栈双人军棋对战系统。

---

## 核心设计与系统亮点

### 1. 现代视觉质感与自然动画
* **液态玻璃棋盘（Liquid Glass Board）**：半透高光琉璃面板、霓虹动态流光铁路线、脉冲波纹安全行营、切角悬浮大本营与东西山界隔离带。
* **液态云母棋子（Liquid Mica Pieces）**：圆角矩形比例设计，深曜黑珍珠与云母白珍珠微光游移质感，烫金/钛银浮雕军衔字效，暗棋神秘防窥背面纹理。
* **自然弹簧位移**：棋子移动采用自然阻尼曲线（Spring Physics），行棋流畅不生硬。

### 2. 流体物理核心动效（重要亮点）
* **吃子动效（液体般融合）**：胜负判定生效后，两枚棋子瞬间化为液滴，通过 **Metaball 表面张力拉伸形成粘性流体桥梁**，败者如水银般顺滑汇入胜者体内，激起层层同心涟漪并带有柔和回弹。
* **对掉动效（液体撞击后消散）**：双方棋子剧烈撞击时表面张力破裂，**向四周瞬间喷溅出 50+ 颗晶莹剔透的液态云母珠滴**，受流体阻尼减速扩散并化为水汽挥发。
* **Web Audio 拟真音效**：纯代码实时合成水滴融合声、液滴破裂飞溅声、落子清脆敲击声与胜利号角。

### 3. 用户定夺采纳的官方争议规则
游戏引擎严格遵循维基百科及您定夺的 5 项争议规则方案：
1. **1A. 工兵铁路拐弯**：工兵只要铁道无阻碍，可**无限任意拐弯变轨飞行**；其他棋子只能沿直线行动。
2. **2B. 常规棋子踩雷**：常规军官踩雷阵亡，**地雷继续保留在原地**；唯有工兵可安全挖雷、炸弹可同归排雷。
3. **3A. 司令阵亡亮旗**：暗棋模式下，己方司令一旦阵亡，系统**立即强制向对方明示亮出军旗位置**。
4. **4A. 炸弹首排布阵**：常规布阵时**严禁将炸弹放置在第一排**（防首回合盲炸）。
5. **5A. 大本营守备**：大本营为驻守要塞，棋子进驻或布阵在大本营后**不可再移出**。

### 4. 主界面布阵工坊与 6 位蓝图码系统
* 主界面提供抽屉式布阵工坊，实时拖拽 25 枚兵力，一键校验合法性。
* 保存后由服务端生成 **6 位英数字蓝图码**（如 `CLASS1`、`A8K9X2`），永久存入后端数据库/JSON 存储。
* PVP 与 PVE 开局时直接输入 6 位蓝图码即可秒速读取阵型。

### 5. 两大彩蛋模式（PVE 蓝图码触发）
在 PVE 模式的蓝图码输入框中输入以下特定代码即刻触发专属对局：
* **`325799` ➔ 启动【雷霆模式】**：
  * 玩家除军旗外，其余 24 枚棋子全部化身为无坚不摧的**【司令】**！
  * 电脑 AI 保持正常阵容，触发金色闪电光芒徽章。
* **`350234` ➔ 启动【炸弹兵模式】**：
  * 玩家第 1～5 排所有停靠点全部变为**【炸弹】**（共 20 枚炸弹）。
  * 第 6 排底线的 3 个兵站棋子变为**【工兵】**。
  * 两个大本营分别进驻**【军旗】**与**【司令】**。

### 6. PVE 人机练棋系统（三大人格）
* **谨慎人格（Cautious）**：深沟高垒，重视大本营防守，司令隐蔽于后方或行营，多派工兵、低阶军官试探探路。
* **平衡人格（Balanced）**：攻守兼备，争夺铁道控制权，炸弹二线待命伏击敌方大将。
* **激进人格（Aggressive）**：疾驰铁轨，主动出击猎杀，利用炸弹强开通路，工兵伺机偷旗。

### 7. PVP 联机系统与房间规则
* **6 位房间码加入**：支持一键复制房号，邀请好友同屏或异地对弈。
* **席位体系**：黑方先手席、白方后手席、观战席。
* **站起与坐下**：非对弈期间，坐在席位上的玩家可点击“站起”进入观战席；任何观战者可在席位出现空缺时点击“坐下”参与对弈。
* **满员自动观战**：房间席位满额后，新进玩家自动成为观战者实时看棋。
* **房主规则面板**：房主在开局前可自由切换“暗棋”与“明棋”模式。
* **中途退场裁判**：对弈中若某方玩家离开或断线，系统立即判负，另一方斩获胜利。

## 快速启动指南

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发环境（前端 + 后端）
```bash
npm run dev
```
* 前端开发服务：`http://localhost:5173`
* 后端 WebSocket 服务：`http://localhost:3001`

### 3. 构建与单端口生产运行
```bash
npm run build
npm start
```
* 生产整合运行在 `http://localhost:3001`

### 4. 运行全套自动化测试
```bash
npm test
```
包含规则合法性校验、工兵飞轨算法、地雷裁决、司令阵亡亮旗、大本营禁出、蓝图编码与两大彩蛋的完整单元与集成测试。
